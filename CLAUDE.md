# Skill Shelf

Situs statis tanpa build: `index.html`, `style.css`, `app.js`, dan data di `skills.json`. Cara nambah skill ada di `README.md`.

## Aturan git

- Jangan push langsung ke `main`. Kerja di branch (`feat/...`, `fix/...`), push branch itu, lalu buka pull request.
- Jangan force push ke `main`.
- Yang merge PR ke `main` adalah Hadi.
